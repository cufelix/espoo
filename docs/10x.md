# Can we get 10x more efficient without losing accuracy?

## What we measured (RoBERTa-base FFN, `experiments/roberta_bits.py`)
| bits/weight (after entropy coding) | vs fp16 | method | fidelity (cos, 1 = identical) |
|---|---|---|---|
| 7.9 | 2.0x | RTN / GPTQ 8-bit | 0.9999 |
| 3.8 | 4.2x | GPTQ 4-bit | 0.985 |
| 2.8 | 5.8x | GPTQ 3-bit | 0.921 |
| 1.7 | 9.3x | GPTQ 2-bit | 0.13 (broken) |

- Exactly lossless storage tops out around **1.4x** (the entropy of bf16
  weights, cf. DFloat11 ≈ 11 bits).
- **Post-training** (no retraining) quantization is near-lossless at ~4x and
  collapses before 10x.
- Entropy coding the integer codes saves another 10–25 % for free
  (2-bit codes: 2.0 → 1.7 bits).
- Caveat: RoBERTa-base is small. Larger LLMs tolerate quantization better,
  so these are pessimistic numbers.

## So 10x needs two things that multiply

### A. Storage ~8–10x: train for it, don't convert after
Models trained or distilled at ~1.6–2 bits (BitNet b1.58 from scratch;
MatQuant int2 with QAT; distillation from the full model on its own outputs)
are reported to roughly match full precision at the same size. Post-hoc
conversion cannot get there (our 2-bit row). Plan: distil the fp16 teacher
into a ternary/2-bit student with *function-space* (activation + logit)
targets, plus entropy coding of the codes.

### B. Speed +1.5–3x, exactly lossless: self-speculation with nested bits
Decoding is memory-bandwidth bound: time per token ≈ bytes of weights read.
Store weights MSB-first as bit-planes (nested like MatQuant). Draft k tokens
reading only the top planes (e.g. 2 of 4 bits → half the bytes), then verify
all k at once with all planes. The output is identical to the full-precision
student (speculative decoding guarantee). There's no second model and no
extra memory.
Prior work is close: QSpec (EMNLP 2025, up to 1.64x, shared weights,
low-bit activations for the draft) and MatQuant (nested int8/4/2). The
bit-plane-*bandwidth* draft is the untested piece.

### Combined estimate
~8x (2-bit student, entropy-coded) × ~1.5–2x (lossless bit-plane
self-speculation) ≈ **12–16x tokens/s per GPU and ~8x less memory vs fp16.**
Accuracy:
- Exactly equal to the 2-bit student.
- Matches the original model only as far as the distilled student does,
  which is the open risk and has to be shown on benchmarks.

## Honest bottom line
- 10x **and** bit-identical output to the original fp16 model: impossible
  by information theory (lossless ≈ 1.4x) plus speculation (≈ 2–3x).
- 10x **and** the same benchmark accuracy: plausible, but only with
  training/distillation (needs GPUs) + lossless speculative decoding.
